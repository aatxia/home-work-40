# React 

Цей проєктпоказує роботу з різними типами компонентів та життєвим циклом у React. 

##  Реалізовані можливості:
1. **Controlled Component:** Форма з текстовим полем та чекбоксом, яка повністю керується станом React (`useState`).
2. **Uncontrolled Component:** Форма підписки, яка використовує референси (`useRef`) для доступу до значень DOM-елементів.
3. **Data Fetching:** Асинхронний запит до `JSONPlaceholder API` з використанням хука `useEffect`. Коректно оброблено стани завантаження (`loading`), успішного отримання даних та помилки.
